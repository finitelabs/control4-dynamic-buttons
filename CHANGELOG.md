## v20261113 - 2026-11-13

### Fixed

- Fixed a button's picture going blank for a moment when Navigator draws it
  again. Refresh Navigators after the update for the fix to show.

### Changed

- Changed a badge's text from 5 characters to as many as fit, up to 20, with
  longer text drawn smaller
- Changed a button on NEEO remotes, and one whose picture hasn't loaded yet, to
  show the driver's icon instead of an empty tile

## v20261112 - 2026-11-12

### Added

- Added the Dynamic Button driver, a Navigator button with up to eight looks set
  up in its Button tab
- Added three icon packs that match the OS 3 and X4 looks, along with hundreds
  of included icons
- Added a search of free icon libraries online
- Added colors, tile shapes, size, position, glow and grayscale for each look's
  picture
- Added badges, and live badges that show a variable's value
- Added My images, so a look's picture can be an uploaded file, pasted SVG, or a
  picture from a web address that can refresh on a schedule or from programming
- Added Look Control, which changes the look on each press, only from
  programming, by other devices' variables, or by the devices bound to the
  looks' Button Links
- Added a Button Link for each look, which a press of the button taps as a
  keypad button does
- Added a timer on each look that shows another look, or the one before, after a
  set time
- Added Show Look, Next Look and Previous Look commands, with a Look variable
  and a Look Changed event
- Added an event for each look and a Look Is conditional
- Added Duplicate, Copy To, Export and Import for looks
